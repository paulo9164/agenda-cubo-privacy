Política de Privacidade

CuboMágicoDesign — aplicação de gestão de diretos ao vivo

ATUALIZADO EM MAIO DE 2025
01 — Introdução

Quem somos

A Agenda Cubo é uma aplicação desenvolvida pela CuboMágicoDesign destinada à gestão e agendamento de diretos ao vivo. Esta política descreve de forma clara quais os dados que recolhemos, como os utilizamos e como os protegemos.

Ao utilizar a Agenda Cubo, aceita os termos descritos nesta política.

02 — Dados Recolhidos

O que recolhemos

A aplicação recolhe apenas os dados estritamente necessários para o seu funcionamento:

  • Nome do cliente — utilizado para identificar e organizar os diretos agendados
  • Data e hora dos diretos — informação necessária para o agendamento
  • Token FCM (Firebase Cloud Messaging) — utilizado exclusivamente para o envio de notificações push ao administrador
  • Identificador anónimo de sessão — gerado automaticamente pelo Firebase Authentication para autenticar o utilizador sem recolher dados pessoais identificáveis
03 — Finalidade

Como utilizamos os dados

Os dados recolhidos são utilizados exclusivamente para:

  • Gerir e apresentar os diretos agendados na aplicação
  • Enviar notificações push ao administrador quando um novo direto é agendado ou alterado
  • Autenticar os utilizadores de forma segura e anónima

Os seus dados nunca são vendidos, partilhados com terceiros para fins comerciais, ou utilizados para publicidade.

04 — Armazenamento

Onde os dados são guardados

Os dados são armazenados na plataforma Google Firebase (Firestore), com servidores localizados na Europa (região eur3). O Google Firebase cumpre o Regulamento Geral de Proteção de Dados (RGPD).

Para mais informações sobre as práticas de privacidade do Firebase, consulte a política de privacidade do Firebase.

05 — Retenção

Durante quanto tempo guardamos os dados

  • Os diretos agendados são automaticamente eliminados após a sua realização
  • Os dados de clientes são mantidos enquanto a conta estiver ativa na aplicação
  • Os tokens FCM são eliminados quando o administrador termina sessão
  • Os identificadores anónimos de sessão são eliminados automaticamente após 15 dias de inatividade
06 — Direitos

Os seus direitos

Ao abrigo do RGPD, tem direito a:

  • Aceder aos seus dados pessoais
  • Solicitar a correção de dados incorretos
  • Solicitar a eliminação dos seus dados
  • Opor-se ao tratamento dos seus dados

Para exercer qualquer um destes direitos, entre em contacto connosco através do endereço indicado abaixo.

07 — Menores

Utilização por menores

A Agenda Cubo não é destinada a menores de 13 anos e não recolhe intencionalmente dados de crianças. Se tiver conhecimento de que uma criança nos forneceu dados pessoais, contacte-nos imediatamente.

08 — Eliminação de Dados

Pedir eliminação dos seus dados

Como pedir a eliminação

Pode solicitar a eliminação de todos os seus dados pessoais a qualquer momento. O pedido será processado no prazo de 30 dias.

✉ Enviar pedido de eliminação
  • Clique no botão acima para abrir um email pré-preenchido
  • Adicione o seu nome no campo indicado
  • Envie o email — responderemos em até 30 dias

Os dados eliminados incluem: nome, diretos agendados e token de notificações. O identificador anónimo de sessão é eliminado automaticamente após 15 dias de inatividade.

09 — Menores

Utilização por menores

A Agenda Cubo não é destinada a menores de 13 anos e não recolhe intencionalmente dados de crianças. Se tiver conhecimento de que uma criança nos forneceu dados pessoais, contacte-nos imediatamente.
